# Image Generation prompts

The built-in Image Generation tool created both PNGs from the earlier face reference. The originals are embedded byte for byte. UV meshes compose these layers without raster modification.

## Base layer

Use case: precise-object-edit. Asset type: animation rig base layer on transparent background. Edit target: the provided face portrait. Preserve EXACT outer silhouette, hair, ears, nose, chin, neck, skin tone, position and scale. Remove ONLY both eyebrows, both eyes including lids and lashes, and mouth including lips: heal these three regions into smooth natural skin matching surrounding lighting. This is a featureless rig base to receive separate eyes, eyebrows and viseme mouth sprite layers. Keep nose intact. No change to portrait framing. Actual alpha transparent background. No extra features, text, borders or shadow outside silhouette.

## Feature atlas

Use case: stylized-concept. Asset type: ONE facial animation feature sprite atlas, transparent alpha background. Reference image: supplied portrait, match identity, warm skin, chestnut eyebrows, brown irises and softly shaded realistic game art exactly. Output square 2048x2048 divided into exactly FOUR equal columns and FOUR equal rows, 16 cells. Every isolated sprite centered at its own cell center, generous transparent margin, no labels or grid lines. No face/head/neck/hair/background: only specified isolated facial feature. Mouth cells must include natural lips, inner mouth, teeth/tongue where visible and minimal feathered skin at lip edges, identical lip width and center across mouth frames. ROW 1 LEFT TO RIGHT: neutral closed lips; speech AH open mouth; speech EE horizontally widened teeth; speech OH round open lips. ROW 2: speech OO pursed round lips; speech FV upper teeth touching lower lip; speech MBP pressed closed lips; joyful open laughing mouth with upper teeth and tongue. ROW 3: each cell contains a symmetrical PAIR of eyes matching reference, both eyes with lids/lashes but no brows: neutral open brown eyes; half lowered eyelids; closed eyelids smiling/squinting; sad moist eyes with puffy lower lids. Eye spacing and eye width identical across these four cells. ROW 4: pair of neutral chestnut eyebrows; pair of sad eyebrows raised inner corners sloping down outside; pair of joyful lifted brows; a pair of clear blue translucent teardrops with bright glints spaced identically to eye centers. All features front facing, grounded believable anatomy, no sticker outlines. Crying/laughing facial acting subtle and believable. Important exact 4x4 equal tile layout, actual transparency, all artwork stays inside its own cell with wide transparent gutters. No text, no watermark.

The tool returned 1254 × 1254 PNGs with alpha. The project uses a 4 × 4 normalized UV atlas, so the requested output dimension does not affect the layout.
