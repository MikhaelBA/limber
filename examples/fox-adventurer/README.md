# Fox Adventurer — نمونهٔ لایه‌ای BoneByBone

فایل اصلی: **Fox-Adventurer.bbbproj**. تصاویر داخل فایل ذخیره شده‌اند؛ برای
بازکردن پروژه نیازی به واردکردن جداگانهٔ PNGها نیست.

## استفاده در برنامه

1. از **Open…** فایل `Fox-Adventurer.bbbproj` را باز کن.
2. برای دیدن حرکت، روی **Animate** بزن؛ در **Timeline** یکی از انیمیشن‌ها را
   انتخاب کن و دکمهٔ پخش یا **Space** را بزن.
3. از **Skins** بین `Teal / red scarf` و `Plum / gold scarf` جابه‌جا شو.
4. برای تغییر شکل، در لیست **Slots** لایهٔ `Scarf — weighted cloth` یا
   `Tunic — weighted mesh` را انتخاب کن و ابزار **Mesh** را بزن.
   در **Setup** هندسهٔ پایه تغییر می‌کند؛ در **Animate** جابه‌جایی رأس‌ها
   کلید **Deform** می‌سازد.
5. ابزار **Weights** وزن‌های موجود را نشان می‌دهد. استخوان‌های شال
   `Scarf upper` و `Scarf tip` هستند؛ لباس به `Chest` و `Root` وزن داده شده است.
6. در **Setup** استخوان `Hand IK target` را انتخاب و جابه‌جا کن تا دست راست
   با IK دنبال آن بیاید. در **Animate** همین کار موقعیت هدف را کلید می‌زند.
7. با **Save** نسخهٔ ویرایش‌شده را ذخیره کن.

## چه چیزهایی داخل پروژه است؟

| بخش       | محتوا                                                                                                |
| --------- | ---------------------------------------------------------------------------------------------------- |
| لایه‌ها   | ۱۶ لایهٔ صورت و گوش‌ها، لباس، کمربند و شلوار، شال، بازوها، ساعدها، دستکش‌ها، ران‌ها، ساق‌ها و بوت‌ها |
| ریگ       | ۱۹ استخوان و یک IK دو استخوانی برای دست راست                                                         |
| مش و Bind | لباس با ۳۰ رأس، شال با ۳۵ رأس، وزن‌های نرمال‌شده و ماتریس‌های Bind                                   |
| Skin      | دو ظاهر کامل؛ مش‌های لباس و شال در ظاهر دوم هندسهٔ مشترک دارند                                       |
| Deform    | تنفس لباس و حرکت شال، با کلیدهای مستقل برای هر ظاهر و منحنی Bezier                                   |
| انیمیشن   | `Idle`، `Wave (IK)`، `March` و `Cloth demo`                                                          |
| Event     | رویداد `hello` در دست تکان‌دادن و `footstep` در قدم‌زدن                                              |
| Marker    | سوکت دست، نقطهٔ تولید افکت، Hurtbox بدن و نقطهٔ تماس زمین                                            |
| تصاویر    | دو PNG شفاف ۱۲۵۴×۱۲۵۴، تولیدشده با ابزار داخلی Image Generation                                      |

تصاویر منبع به‌صورت اطلس قطعات جدا هستند. هر لایه با UV بخش خودش را انتخاب
می‌کند و در پروژه مستقل از بقیه حرکت می‌کند؛ PNGهای تولیدشده دست‌کاری نشده‌اند.
انتخاب UV تخت‌ترین کلاهک‌های مفصل و کمربند تکراری را بیرون از لایه نگه می‌دارد.
تعویض Skin هندسهٔ لباس و شال را مشترک نگه می‌دارد، اما تکسچر، وزن‌ها، Bind و
کلیدهای Deform هر نمونه مستقل‌اند.

این نمونه از قابلیت‌های فعلی استفاده می‌کند. راه‌رفتن یک حرکت کارتونی درجا است؛
Physics یا Path Constraint ندارد و پایان فاز ۷ را ادعا نمی‌کند.

## فایل‌های همراه

- `character-preview.png`: پیش‌نمایش تمیز دو ظاهر در حالت Idle و Wave.
- `editor-preview.png`، `editor-wave.png`، `editor-wave-gold.png` و `editor-mesh.png`: تصاویر داخل خود ادیتور.
- `fox-atlas.png` و `fox-atlas-golden.png`: تصاویر اصلیِ تغییرنیافته.
- `generation-prompts.md`: متن کامل دو پرامپت و ورودی مرحلهٔ ویرایش.
- `validation.json`: نتایج آزمون پروژه و مرورگر.

## آزمون و بازسازی

از ریشهٔ مخزن، پس از نصب وابستگی‌ها:

```powershell
node examples/fox-adventurer/build-project.mjs
node examples/fox-adventurer/verify-project.mjs
npm run dev -- --host 127.0.0.1 --port 5173
```

در ترمینال دوم:

```powershell
node examples/fox-adventurer/preview-and-smoke.mjs
```

آزمون‌ها از Core و Runtime واقعی پروژه استفاده می‌کنند: بازخوانی دقیق فرمت
Native، تطابق تصاویر جاسازی‌شده با PNGهای اصلی، حفظ هندسه در Bind، ۲۱۶۰ فریم
از هشت ترکیب Skin/Animation، حرکت Deform، خروجی محدود و متناهی، دنبال‌کردن هدف IK
و اجرای Eventها. آزمون مرورگر Open، پخش، تعویض Skin، انتخاب Mesh و Weights،
Save و بازکردن مجدد را بررسی می‌کند. هیچ تغییری در کد برنامه برای این نمونه لازم نبود.
